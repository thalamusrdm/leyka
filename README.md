# Leica Eyecare ישראל

אתר תדמית בעברית עבור Leica Eyecare בישראל, עם תמיכה ב־RTL ותצוגה מותאמת למחשב ולמובייל.

## הרצה

נדרשת Node.js. אין תלויות חיצוניות להתקנה.

```sh
npm start
```

התצוגה המקומית זמינה ב־http://127.0.0.1:4173.

## בנייה ובדיקות

```sh
npm run build
npm test
```

קובצי המקור נמצאים ב־src, והאתר הסטטי והמדיה ב־dist. לפריסה בשרת סטטי יש להגדיר את dist כתיקיית הפלט.

טופס יצירת הקשר פותח הודעת דוא״ל במכשיר המשתמש.
